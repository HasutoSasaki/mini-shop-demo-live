# デモ用 issue 下書き

GitHub にリポジトリを作ったあと、以下を issue として登録する。
本番ではリハの実行時間に合わせて S / M / L のどれかを使う（本命は M）。

## S: ヘッダーの「カート」に商品点数を表示する

### 依頼

ヘッダーの「カート」に、今カートに入っている商品の点数をバッジで表示してほしい。

### 受け入れ条件

- 商品をカートに入れると、ヘッダーの「カート」に点数（例: 3）が表示される
- カートが空のときはバッジを表示しない
- `pnpm test` が通る
- 動作確認のスクリーンショットを PR 本文に添付する

## M: 5,000円以上で送料無料にして、あと何円かを表示する

### 依頼

カートの小計が 5,000 円以上のときは送料を無料にして「送料無料」と表示してほしい。
5,000 円未満のときは「あと ○円で送料無料」と表示して、追加購入を促したい。

### 受け入れ条件

- 小計 5,000 円以上: 送料 0 円になり、カート画面に「送料無料」と表示される
- 小計 5,000 円未満: 送料 500 円のまま、「あと ○円で送料無料」と表示される（○ は 5,000 − 小計）
- カートが空のときはどちらも表示しない
- 送料の判定と残額の計算は `src/lib/cart.ts` に置き、テストを追加する
- 既存のテストと追加したテストがすべて通る
- 動作確認のスクリーンショットを PR 本文に添付する

## L: クーポンコードを入力できるようにする（M と組み合わせる）

### 依頼

カート画面にクーポンコードの入力欄を追加してほしい。`WELCOME10` を入力すると小計から 10% 引きになる。

### 受け入れ条件

- カート画面に入力欄と「適用」ボタンがある
- `WELCOME10` を適用すると「クーポン割引 −○円」の行が出て、合計が 10% 引きになる
- それ以外のコードは「無効なクーポンです」と表示し、金額は変わらない
- 送料無料の判定は割引後の小計で行う
- 割引の計算は `src/lib/cart.ts` に置き、テストを追加する
- 動作確認のスクリーンショットを PR 本文に添付する

## 予備

- 在庫切れ（`stock` が 0）の商品に「売り切れ」を表示し、「カートに入れる」を押せなくする
- 価格の安い順・高い順で並び替える
- お気に入りボタン
- 検索結果 0 件のときにおすすめ商品を表示する
